
# 🗼 TOWER OF HANOI

## 📌 Project Description
Tower of Hanoi is a classic mathematical puzzle game developed using HTML, CSS, and JavaScript.

The objective is to move all disks from Tower A to Tower C by following the game rules.

## 🎮 Features
- Interactive Tower of Hanoi game
- Three towers (A, B, C)
- Supports 3 to 7 disks
- Automatic solution
- Move counter
- Minimum moves calculation
- New Game option
- Winning message

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📖 Rules
1. Move only one disk at a time.
2. Only the top disk can be moved.
3. A larger disk cannot be placed on a smaller disk.
4. Move all disks from Tower A to Tower C.

## 🧮 Formula

Minimum number of moves:

M = 2^n - 1

Where n is the number of disks.

Example:
For 3 disks:

M = 2^3 - 1 = 7 moves.

## 🚀 How to Run
1. Download the repository.
2. Open the project folder.
3. Open tower_of_hanoi.html in Chrome.
4. Select the number of disks.
5. Click New Game and start playing!
